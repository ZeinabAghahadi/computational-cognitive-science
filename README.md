# کتابچهٔ علوم شناختی محاسباتی

**فارسی** | [English](README.en.md)

این کتابچه برای درس **علوم شناختی محاسباتی** در دانشگاه علم و صنعت ایران تهیه شده است و میان مبانی علوم شناختی و مدل‌های محاسباتی معاصر زبان، گفتار، تصمیم‌گیری، شبکه‌های عصبی اسپایکی و هم‌ترازی مغز و مدل پیوند برقرار می‌کند.

## مطالعهٔ کتابچه

- [نسخهٔ فارسی Markdown](book/fa/README.md)
- [نسخهٔ انگلیسی Markdown](book/en/README.md)
- [نسخهٔ فارسی PDF](releases/computational-cognitive-science-booklet-fa.pdf)
- [کد منبع LaTeX](latex/main.tex)

## مشخصات کتابچه

- **نویسنده:** دکتر زینب آقاهادی
- **وابستگی سازمانی:** دانشکدهٔ مهندسی کامپیوتر، دانشگاه علم و صنعت ایران
- **ویرایش:** نسخهٔ ۱٫۰، بهار ۱۴۰۵
- **زبان:** نسخه‌های Markdown فارسی و انگلیسی؛ نسخهٔ PDF فارسی با صفحهٔ عنوان و چکیدهٔ انگلیسی
- **قالب:** A4، در ۱۶۴ صفحه

## ساخت PDF از کد منبع

برای حروف‌چینی فارسی از `xepersian` استفاده شده است؛ بنابراین سند باید با XeLaTeX و یک نصب نسبتاً کامل TeX Live یا MacTeX ساخته شود.

```bash
make
```

برای حذف فایل‌های موقت ساخت:

```bash
make clean
```
